# web-socialize

A cinematic, scroll-driven landing page prototype for Socia-lize — an AI social media operating system.

## Experience

The page tells the product story through four stages:

1. Understand — a brand document is scanned and separated into logo, colors, typography, tone, and audience.
2. Create — one campaign prompt becomes platform-specific content cards.
3. Schedule — generated posts land inside a visual publishing calendar.
4. Learn — performance data becomes reusable agent context for the next campaign.

The desktop experience uses pinned scroll scenes and scrubbed timelines. Mobile keeps the same narrative with lighter layouts, and reduced-motion preferences are respected.

## Stack

React + Vite, GSAP + ScrollTrigger, Lenis smooth scrolling, Motion for micro-interactions, Lucide React icons, and plain CSS for the prototype design system.

## Run locally

Install dependencies with npm install, then run npm run dev.

For a production build, run npm run build and then npm run preview.

## Direction

This repository starts with the animated landing-page prototype. The next iteration can add real image-sequence/canvas assets, product screenshots, and a dedicated Three.js scene only where true 3D materially improves the story.
